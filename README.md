# SFXR

Sound effects for people who make things.

SFXR turns Persian scene descriptions into practical English SFX-library search queries. It also has a simple search mode for turning a Persian sound request into an English query.

## Run locally

1. Install Node.js 20+.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local`.
4. Add your OpenAI API key to `OPENAI_API_KEY`.
5. Run `npm run dev`.

The API key is server-side only and must never be committed to GitHub.
